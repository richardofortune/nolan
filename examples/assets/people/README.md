# Presenter faces (AI-generated)

These are **AI-synthesized faces of people who do not exist** — generated by a
StyleGAN model (via `this-person-does-not-exist.com`), not photographs of real
individuals. They're bundled as placeholder presenter avatars for the demos:
point a cast member's `cam` at one.

```jsonc
"cast": { "host": { "kind": "human", "name": "Mia", "cam": "./assets/people/woman-1.jpg" } }
```

Because no real person is depicted, there's no likeness or privacy concern in
using them as demo avatars. For a production video, swap in a real headshot.
